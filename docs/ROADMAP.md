# Roadmap

Completed foundations include a lazy workspace tree, local xterm.js PTY, encrypted multi-provider settings, and unsigned native packaging configuration.

1. Document model, Monaco editor, tabs, atomic save, hot exit, and recovery.
2. Streaming search, typed general settings, and read-only Git status/diff.
3. Terminal process isolation hardening, diagnostics, and project-aware integration tests.
4. Permissioned LSP process management and language features.
5. Provider-neutral AI requests, inspectable context, permission engine, reviewable patches, and evaluations.
6. Later phases: extension sandbox, profiles, DAP, remote development, collaboration, profiling, signed releases, and updates.

Each phase requires type-check, lint, tests, build, documentation, security review, and real behavior verification before completion.
